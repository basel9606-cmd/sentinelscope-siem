# SentinelScope SIEM — نص فيديو ديمو (45 ثانية)

## 0–5 ثوانٍ — الافتتاح

**الشاشة:** صفحة Alerts في SentinelScope.

**التعليق:**

> هذا SentinelScope، لوحة SIEM مصممة لمحلل SOC لمتابعة التنبيهات والتحقيق فيها بسرعة.

## 5–15 ثانية — وصول التنبيه

**الشاشة:** أظهر تنبيه Wazuh في قائمة التنبيهات.

**التعليق:**

> تصل التنبيهات من Wazuh عبر بوابة إدخال محمية، ثم تظهر هنا مع مستوى الخطورة والأصل وتقنية MITRE ATT&CK.

## 15–30 ثانية — التحقيق

**الشاشة:** اضغط **Investigate** على أحد التنبيهات.

**التعليق:**

> بضغطة واحدة يفتح التحقيق: الجهاز أو المستخدم المتأثر، سياق التنبيه، مستوى الثقة، وخطوات الاستجابة المقترحة للمحلل.

## 30–40 ثانية — إدارة القضايا

**الشاشة:** افتح قسم Cases.

**التعليق:**

> يمكن للفريق إنشاء قضية، تعيين المسؤول، متابعة حالة التحقيق، وتوثيق الخطوات ضمن سير عمل واضح.

## 40–45 ثانية — الإغلاق

**الشاشة:** عد إلى Overview أو أظهر الشعار.

**التعليق:**

> SentinelScope يحول التنبيهات إلى تحقيقات منظمة وقابلة للتنفيذ. جاهز للتكامل مع بيئة SOC الخاصة بك.

## التسجيل

- افتح `http://127.0.0.1:8767/#alerts` أثناء تشغيل الخادم المحلي.
- سجّل الشاشة بدقة 1080p، وبسرعة بطيئة وواضحة.
- لا تعرض مفاتيح API أو عناوين IP حقيقية أو بيانات عملاء.
